# 🛋️ Dec Hogar

Aplicación de e-commerce desarrollada en React + Vite para la venta de productos para el hogar, como respaldos, almohadas y más.

---

## 🚀 Tecnologías utilizadas

- ⚛️ React
- 🧭 React Router DOM
- 🔥 Firebase (Firestore)
- 🎨 CSS
- 🧱 Vite
- 📦 React Icons

---

## 🧩 Funcionalidades principales

- Navegación por categorías
- Visualización del detalle de cada producto
- Agregado al carrito con control de stock
- Carrito con listado y total
- Checkout con formulario de compra
- Registro de órdenes en Firebase
- Footer con enlaces y redes sociales
